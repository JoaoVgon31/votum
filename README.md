# votum
Plataforma web modular para orquestração de processos deliberativos e votações nos cenários de eleição para presidente, eleição de centro acadêmico e assembleias de condomínio. Alinhado ao ODS 16 da ONU (Paz, Justiça e Instituições Eficazes), o sistema busca assegurar transparência, legitimidade e auditabilidade nas tomadas de decisão coletivas.
